# Calculadora de Média do Aluno

Sistema simples em Python que calcula a média entre duas notas e informa se o aluno foi aprovado ou reprovado.
 ***
## Tecnologias Utilizadas

- Python 3
***
## Como Instalar e Executar

1. Certifique-se de ter o Python 3 instalado em sua máquina.
2. Clone ou baixe este repositório.
3. No terminal, navegue até a pasta do projeto.
4. Execute o comando:

```bash
python calculadora_media.py
```

5. Digite as duas notas solicitadas quando o programa pedir.
***
## Exemplo de Uso

```
=== Sistema de notas do aluno ===
Digite a primeira nota: 8.5
Digite a segunda nota: 7.0
A média final é: 7.75
Status: APROVADO
```
